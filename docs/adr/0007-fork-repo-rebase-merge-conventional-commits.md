# ADR-0007: Fork repo, rebase-merge, Conventional Commits

- Status: accepted (2026-10-30, user decision)

## Decision
- The submission repo is the fork `Tanbin-CS/solmate` on `main`.
- The `prototype/jezero` branch is frozen; the upstream repo is unused.
- Merge by rebase only, with linear history and a ruleset requiring 9 checks.
- Every commit is a Conventional Commit with a body, enforced by commitlint
  locally and in CI.

## Consequences
- `git log` reads as a meaningful changelog for judges.
- CHANGELOG is generated by git-cliff.
